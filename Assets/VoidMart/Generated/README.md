# Generated

Everything in this folder is produced by **Tools ▸ Void Mart ▸ ⚡ One-Click Setup**
(or the individual *Rebuild* buttons in the Master Control window).

Nothing here is hand-authored, so it is always safe to delete the whole folder and
regenerate. Sub-folders:

| Folder      | Contents                                                        |
|-------------|-----------------------------------------------------------------|
| `Config/`   | ScriptableObject configuration (GameConfig, nodes, products...) |
| `Materials/`| Clay / UI / stencil materials built from the theme palette      |
| `Meshes/`   | Procedural low-poly props, vehicles, machines, characters       |
| `Textures/` | Palette-driven sprites, icons, gauges, font atlas               |
| `Audio/`    | Synthesised music loops and SFX (16-bit PCM WAV)                |
| `Prefabs/`  | Assembled gameplay + UI prefabs                                 |
| `Scenes/`   | `Boot.unity` and `Game.unity`                                   |
